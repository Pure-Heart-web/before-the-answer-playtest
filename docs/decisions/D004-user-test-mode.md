# D004：用迁移能力而非满意度验证原型

## 核心假设

如果游戏真的训练了现实判断，玩家不只会记住“正确选项”，还应该能在陌生人物、行业和资源条件下主动提出需要补足的认识、最小验证和止损条件。

## 测试流程

1. 游玩前回答AI求职辅导案例，记录初始判断。
2. 完成三幕剧情，记录探索、证据、假设、剧情选择和回溯次数。
3. 通关后回答餐饮短视频案例，避免复述原案例。
4. 比较两次回答主动纳入的七类维度：真实问题、交易证据、最小验证、交付经济、责任风险、环境替代、止损与重返。
5. 收集玩家对主观能动性、因果清晰度和继续游玩意愿的评价。

## 隐私与解释边界

- 不收集姓名、联系方式、设备标识或精确年龄。
- 所有内容默认保存在浏览器本地，玩家主动导出后才形成文件。
- 不把维度数量称作能力分、智力分或创业成功概率。
- 文本匹配只是研发观察工具，无法判断回答整体质量。

## 首轮测试的停止条件

如果多数玩家只是在迁移题中复述界面关键词，或无法说明前一幕如何改变后一幕，就暂停扩充剧情，优先修改证据呈现和复盘方式。
