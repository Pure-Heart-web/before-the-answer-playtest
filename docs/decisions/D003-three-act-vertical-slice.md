# D003：先完成一个三幕剧情切片

## 要验证的问题

玩家能否感觉到人物、证据和关系是可调动的社会资源，并理解前一幕的认识为什么改变后一幕的行动结果。

## 三幕结构

1. **夸奖与账本**：区分观点、过去行为和真实损失。
2. **第一份报价**：把损失证据推进到范围、价格、付款和责任边界。
3. **零价浪潮**：环境改变后，重组已有认识并选择产品、服务、平台合作或战略退出。

## 人物设计

- 唐曼：拥有问题与采购权，但关心预算、数据和责任。
- 徐岚：提供鼓励与熟人关系，但没有当前采购预算。
- 程屿：代表现金生存与就业选择，不是“反对创业”的工具人。
- 顾遥：能提供平台流量，也会控制渠道与客户入口。

每个人物都有独立利益，不按“帮助玩家/阻碍玩家”划分善恶。

## 因果连接

- 第一幕发现过去损失，第二幕的限定报价才可能变成真实定金。
- 第一幕只获得称赞，第二幕即使报价形式完整也可能无法成交。
- 第二幕的付款、审核与责任证据进入认知云图，并参与第三幕理解强度判定。
- 第三幕选择结果反过来改变客户或平台人物关系。

## 暂时限制

- 场景仍以文字、构图和人物卡表现，没有昂贵的电影化资源。
- 每幕只保留三个高信息密度选择，先测试因果是否清楚。
- 人物关系目前影响反馈与资源感知，尚未形成更复杂的关系事件链。
