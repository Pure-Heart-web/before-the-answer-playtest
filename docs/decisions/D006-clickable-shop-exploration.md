# D006：第一幕先验证可点击空间探索

日期：2026-09-10  
状态：已采用

## 决策

v0.8 不扩充更多静态剧情插画，也暂不迁移到完整游戏引擎。先把第一幕的雨夜小店做成一个可点击调查空间，验证“观察—解释—承担不确定性—行动”是否能成为真正的游玩循环。

## 规则

- 账本、消息、旧报价与店主是四种信息价值不同的调查点。
- 每次调查消耗42天总时间池中的1—2天，同时可能消耗现金和精力。
- 调查结果固定拆成事实、推测、未知三层；弱线索不会自动升级成强结论。
- 玩家取得一条线索后即可停止调查，也可以继续付出时间补足认识。
- 相关线索会缩短第一幕追问过去损失所需时间；明知店主约束仍强推展示，则会产生额外关系代价。
- 调查顺序和停止位置进入匿名导出记录，供用户测试分析。

## 为什么现在做

本作品的核心风险不是画面数量不足，而是玩家是否真的会把信息价值和行动代价放在一起思考。一个小而完整的可调查场景，比继续增加被动剧情更早暴露机制问题。

## 后续判断

如果真实玩家会主动比较调查点、在不同位置停止，并能解释线索如何改变了后续选择，再扩展第二个空间场景；如果多数玩家仍把热点当收集品，则先调整信息结构、时间压力和反馈，不扩图量。
