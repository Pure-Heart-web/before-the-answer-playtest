# D002：用“世界模型准确度 × 行动匹配度”驱动剧情分支

## 目标

让玩家不再只是观看已经写好的主线，而是从支线经历中取得事实、形成自己的社会理解，并让这份理解真实改变主线行动与后果。

## 本版决定

1. 支线行动解锁认知云图节点，节点必须能追溯到观察、过去行为、付款、交付或风险边界。
2. 主线挑战要求玩家用自然语言写下当前理解，再选择行动方向。
3. 原型使用可解释的关键词/近义概念匹配；文本猜中但未经经历支持的认识只算“推测”，不能单独获得最强结果。
4. 四个行动方向各有弱、部分、强三档作者分支，共十二条演出结果。
5. “正确”只指更符合本场景可验证因果的判断，不把就业、创业、合作或退出设成道德高低。
6. 失败可以认知回溯：资源回到挑战前，但因果教训被保留，避免只靠盲目重选。

## 暂不采用

- 不接入运行时大模型自由生成剧情。当前需要先验证玩家是否愿意阅读线索、写下理解并接受因果反馈。
- 不扩展为几十条主线。先用一个外部挑战检验十二分支是否能被玩家感知为“我的理解改变了故事”。
- 不把所有现实问题设计成唯一答案。可验证事实存在高低，但价值取向和风险承受能力允许产生多条合理路线。

## 下一轮用户测试观察

- 玩家写下的内容是在认真解释因果，还是只为猜关键词？
- 玩家能否说明支线经历如何影响主线判断？
- 失败复盘后，玩家第二次的理解是否真的变化？
- 四个强分支是否都显得合理且具有不同代价？
