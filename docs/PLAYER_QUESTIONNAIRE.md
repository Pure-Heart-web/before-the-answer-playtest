# 《在答案之前》v0.8.1 玩家调研问卷

## 使用位置

问卷位于匿名测试线的终幕：玩家先完成游玩前基线案例、正常游戏和陌生行业迁移案例，再看到问卷。预计填写时间约2分钟。

不要在游玩前展示题目，以免“时间代价”“主角自主”等措辞提示玩家应该注意什么。

## A. 还原调查决定

### 1. 哪条现场线索最影响你后来的判断？

只显示玩家实际调查过的线索，另有“没有一条具体线索”。该题用于区分“点击过”与“真正影响判断”。

### 2. 你为什么在那个位置停止小店调查？

- 信息已经够我行动
- 继续调查不值得时间
- 想尽快看到剧情结果
- 我把能点的都查完了
- 当时没意识到可以继续
- 其他或说不清

该题需要与实际调查顺序交叉查看。例如玩家选择“时间不值得”，但仍查完全部热点，说明他的回忆、界面理解或实际行为至少有一处需要继续访谈，不能只采信选项。

## B. 六项体验量表

每项使用1—5分语义差异量表。1对应左侧描述，5对应右侧描述。

1. 我的理解确实改变了故事：只是旁观 → 真正参与
2. 我能理解主要结果为什么发生：难以解释 → 因果清楚
3. 调查小店时，我在主动寻找信息：像点任务按钮 → 像调查现场
4. 时间代价影响了我是否继续调查：没有影响 → 明显影响
5. 林澈像一个有自己判断的人：只是执行按钮 → 有自己的边界
6. 我愿意继续接下一个人生委托：到此为止 → 很想继续

六项指标分别对应能动性、反馈可解释性、空间探索感、资源压力、人物自主性和继续意愿。不要合并成单一“游戏质量分”。

## C. 开放反馈

### 高光记录

哪一刻最影响了你的判断？

### 异常记录

哪一处最困惑、无聊或像考试？

“异常记录”要求至少填写4个字符；“高光记录”允许留空，避免强迫没有高光的玩家编造正面反馈。

## 推荐的口头追问

问卷提交后，主持人只选择一到两个矛盾点追问：

- 你说时间代价影响很大，具体在哪一刻决定不再查了？
- 你点过这条线索，但选择它没有影响判断，为什么？
- 你认为林澈有自己的边界；是哪次接受、调整或拒绝让你这样觉得？
- 如果删掉一个环节，最希望删掉哪个？

避免追问“你是不是学会了先验证需求”，这会暴露期待答案并诱导迎合。

## 解释边界

- 五至十人的问卷适合发现明显体验问题，不足以证明学习效果。
- 自评分数不能代替玩家的实际调查顺序、剧情选择和迁移回答。
- “选择正确分支”不等于掌握现实创业能力。
- 玩家选择退出或低成本路线，不应被解释为消极或失败。
