# 《在答案之前》v0.8

一个关于创业认知、有限时间和协商式角色控制的浏览器网页原型。

## 试玩

在本目录运行：

```bash
npm run dev
```

然后打开 `http://localhost:4173`。

## 测试

```bash
npm test
```

## 本版验证什么

- 探索与行动共享42天时间池，是否形成真实机会成本。
- 玩家能否借证据形成、调整并验证商业假设。
- 主角是否像一个有性格和判断的人，而不是玩家的鼠标。
- 高风险、低证据建议是否会伤害事业和信任。
- 结局是否能分别呈现业务结果与创业认知能力。
- 支线经历能否在“认知云图”中形成可追溯的社会理解。
- 玩家能否先自由写下当前理解，再让理解与行动共同改变主线演出。
- 失败后的因果复盘与认知回溯，能否促进理解而不是鼓励穷举选项。
- 玩家能否把局内方法迁移到一个人物、行业和资源条件都不同的新案例。

## v0.4 匿名用户测试模式

开场选择“作为匿名测试者开始”，将依次完成：

1. 游玩前陌生案例基线判断。
2. 正常三幕游玩，后台只记录局内选择与证据指标。
3. 通关后的新行业迁移案例。
4. 三项1—5分体验评价，以及最有用和最困惑的开放反馈。
5. 在本地导出一份JSON测试记录。

测试不收集姓名、联系方式或设备信息，数据默认只保存在浏览器本地。维度分析用于比较玩家主动纳入了哪些因果因素，不是人生能力分数。

## v0.5 研究者观察台

打开 `http://localhost:4173/research.html`，可以：

- 一次选择多份玩家主动发送的匿名JSON记录。
- 查看基线与迁移案例中七类因果维度的群体变化。
- 汇总剧情路线、回溯、证据强度和三项体验评价。
- 并排阅读“最有用”和“最困惑”的开放反馈。
- 将逐局汇总导出为CSV。
- 载入三份明确标记的演示数据，预览真实测试前的分析界面。

所有解析在当前浏览器中完成，刷新页面即清空导入内容。首轮执行方法见 [USER_TEST_GUIDE.md](./USER_TEST_GUIDE.md)。

## v0.6 可发布静态包

运行 `npm run build` 会生成 `dist/`：根地址为测试邀请页，游戏位于 `game.html`，并包含隐私说明和研究者观察台。构建过程会检查本地资源引用，并阻止发布产物残留 `localhost` 地址。

仓库还包含 GitHub Pages 自动发布工作流和结构化试玩反馈表单。具体发布步骤见 [DEPLOYMENT.md](./DEPLOYMENT.md)；当前仍定位为小范围邀请测试，而不是大范围公开研究。

## v0.7 电影化表现切片

- 三张原创场景插画分别表现毕业前的城市地平线、小店验证现场与平台冲击下的终幕抉择。
- 主舞台会随剧情阶段切换画面，并把“当前目标”放回世界场景，而不是只放在控制面板里。
- 浏览器原生合成低强度环境音景；证据、风险、拒绝和成功拥有不同提示音，可随时关闭。
- 匿名测试被重新包装为“序章委托—番外任务—终幕复盘”，结算分析会在玩家提交体验反馈后才出现，减少考试感和答案提示。
- 保留原有模拟规则与匿名数据结构，使 v0.6 与 v0.7 的核心玩法结果仍可比较。

## v0.8 可点击探索场景

- 第一幕的雨夜小店成为可调查空间：玩家可以查看补登账本、工作手机、旧报价单，或带着具体痕迹请求店主停下来交谈。
- 每个调查点消耗同一个42天资源池，并明确区分“看见的事实、当前推测、仍然未知”，避免把点亮热点误写成自动获得正确答案。
- 玩家调查一处后即可停止，也可以继续花时间补足认识；已获得的现场线索会改变后续提问效率与人物反馈。
- 匿名测试会记录调查顺序与停止位置，用来验证玩家是否真的在权衡信息价值，而不是穷举收集品。

## v0.3 三幕剧情切片

当前主线由三个连续场景构成：

1. **夸奖与账本**：在礼貌性兴趣、忙碌客户和过去行为之间选择怎样获取认识。
2. **第一份报价**：处理价格、范围、AI错误、隐私责任和现金生存压力。
3. **零价浪潮**：大型平台免费开放类似功能，玩家写下理解并选择最终行动方向。

唐曼、徐岚、程屿和顾遥拥有不同利益立场与关系值。前一幕获得的证据会改变后一幕交易是否成立，人物关系也会随建议发生变化。

## v0.2 认知主线

完成至少一次现实探索后，可以进入“零价浪潮”：大型平台将AI工具免费，玩家需要先写下对局势的理解，再从产品化、结果型服务、平台合作、战略退出中选择方向。

原型会把文字按本地关键词与近义概念匹配到六类因果节点，并结合已经探索获得的证据，进入 4 × 3 共十二个作者预设分支。它验证的是玩法结构，不使用运行时生成式 AI；等真实用户证明这条动线有趣后，再替换为更稳健的语义分类器。

这是一份教学与玩法原型，不构成现实中的投资、法律、税务或职业建议。
